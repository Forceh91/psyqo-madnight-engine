# API Reference

This section documents the engine's public classes and functions, organized by subsystem. It's written from the engine source directly — where a class's intent isn't obvious from its name, the description below explains what it's for and how it's meant to be used.

Most of the engine is exposed as classes with `static` methods acting on static member state (managers), rather than instances you construct yourself — a natural fit for a fixed-memory, no-heap-allocation target like the PS1. A handful of types (`GameObject`, `Camera`, `Billboard`, `ParticleEmitter`, `Menu`, HUD elements) are regular value/instance types you create and own yourself, usually via a manager's `Create*` call.

- [Core](./core) — `GameObject`, `GameObjectManager`, billboards, particles, debug tooling
- [Render](./render) — `Camera`, `Renderer`, `Lighting`, colour helpers, clipping
- [Mesh & Animation](./mesh-and-animation) — `MeshManager`, skeletons, `AnimationManager`, `Quaternion`
- [Physics & Collision](./physics-and-collision) — `Collision`, `Raycast`, `ColbinManager`, collision types
- [Controller](./controller) — pad input helpers
- [Math](./math) — GTE-accelerated matrix/vector helpers, lerp, trig, RNG
- [Sound](./sound) — `SoundManager` (VAG/SPU), `ModSoundManager` (MOD tracker music)
- [Textures](./textures) — `TextureManager`
- [UI](./ui) — `GameplayHUD`, HUD elements, `Menu`
- [Helpers](./helpers) — CD-ROM/archive loading, load queues, world-space unit literals

This reference was generated by reading the header files directly, since public API Doxygen coverage is still sparse in places.
